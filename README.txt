# ResolveJá — protótipo

Abra `index.html` no navegador para testar.

## Acesso administrativo de demonstração
Usuário: ADM
Senha: RESOLVEJA

O acesso "Conta Mestre" no protótipo pode ser aberto usando:
Usuário: mestre

A senha real da conta mestre NÃO foi colocada no código.

## Importante
Este é um protótipo front-end. Login, banco de dados, verificação de profissionais, avaliações verificadas, anti-spam/Anti-ZAP, banimento por identidade e auditoria precisam ser implementados no servidor antes de colocar o sistema em produção.
